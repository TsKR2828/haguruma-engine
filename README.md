# 歯車 — 沉浸式文字解謎引擎

> 芥川龍之介遺稿《歯車》的互動式文學體驗  
> React 資料驅動架構 · 日中雙語

---

## 這是什麼

將芥川龍之介 1927 年的遺稿《歯車》改編為可互動的沉浸式閱讀體驗。不是「遊戲化文學」，而是「讓文學的閱讀行為本身成為遊戲機制」。

玩家的選擇不改變故事走向——芥川的命運是確定的。選擇改變的是「你觀察到了什麼」和「你如何理解你觀察到的」。

## 核心機制

- **三軸系統**：神經（遞減，驅動視覺崩壞）/ 洞察（累加，觀察的回報）/ 執筆（累加，作家身份的存續）
- **手帖**：追蹤反覆出現的文學意象（雨衣、齒輪、翼、書物...），累積到閾值可觸發「連結」
- **視覺崩壞**：神經值下降時，畫面暗角加深、雜訊疊加、文字亂碼——精神瓦解的視覺化
- **日中雙語**：日文原文在上，中文翻譯在下

## 技術架構

- React 資料驅動：場景是 JSON 資料，渲染器是通用元件
- 引擎合併自兩個原型：歯車 React 原型 + 最後一封信 CoC 引擎 v27
- 詳見 [ENGINE_SPEC.md](ENGINE_SPEC.md)
